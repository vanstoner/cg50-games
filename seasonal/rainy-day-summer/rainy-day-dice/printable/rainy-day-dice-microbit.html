Rainy day

RAINY DAY DICE

Turn a micro:bit into five dice! Shake to roll, hold the ones you want, and score them on this sheet. A dice game for 2 to 4 players.

1How to play

  1. Shake the micro:bit to roll all five dice.
  2. Want to keep some? Press A to pick a die, and B to hold it (beep beep) or let it go again (looong beep).
  3. Shake again to roll the dice you didn't hold. You get 3 rolls in a turn.
  4. After the third roll the micro:bit plays a tune and scrolls your five numbers. Choose one empty box below and write your score in it.
  5. Pass it on: the next player shakes to start their turn.

After 13 turns each, every box is full. The highest grand total wins!

2Reading the dice

13246

Each column is a die. Count the lights from the bottom. A 6 is too tall to fit, so its column flashes. Bright dice are held; dim ones will roll.

Press A to look at one die close up. It shows the die's number first (1 to 5), then its face. Keep pressing A to go back to all five.

4Type the code

Go to python.microbit.org and type in both halves, left then right. Python is fussy about the spaces at the start of lines: they show which lines belong together.

from microbit import *
import music
import random

# The six dice faces: 9 = a dot, 0 = no dot1
FACES = [Image("00000:00000:00900:00000:00000"),
         Image("00009:00000:00000:00000:90000"),
         Image("00009:00000:00900:00000:90000"),
         Image("90009:00000:00000:00000:90009"),
         Image("90009:00000:00900:00000:90009"),
         Image("90009:00000:90009:00000:90009")]

dice = [1, 1, 1, 1, 1]   # the five dice2
held = [False] * 5       # which dice are held
rolls = 0                # rolls used (3 max)
chosen = -1              # picked die (-1 = none)

def show_dice():3
    # One column per die: count the lights
    picture = Image(5, 5)
    flash = running_time() // 300 % 2
    for x in range(5):
        height = dice[x]
        if height == 6:
            height = 5 * flash   # too tall: flash
        level = 3                # dim = not held
        if held[x]:
            level = 9            # bright = held
        for y in range(height):
            picture.set_pixel(x, 4 - y, level)
    display.show(picture)

def roll():4
    # Rattle, then roll the dice that aren't held
    for i in range(8):
        display.show(random.choice(FACES))
        music.pitch(random.randint(200, 800), 40)
    for x in range(5):
        if not held[x]:
            dice[x] = random.randint(1, 6)
display.scroll("SHAKE!")
while True:
    if accelerometer.was_gesture("shake"):5
        if rolls == 3:          # next player's go
            held = [False] * 5
            rolls = 0
        roll()
        rolls = rolls + 1
        chosen = -1
        if rolls == 3:          # turn over: write it down6
            music.play(music.POWER_UP)
            text = ""
            for d in dice:
                text = text + str(d) + " "
            display.scroll(text)
        else:
            display.show(3 - rolls)  # rolls left
            sleep(600)

    if button_a.was_pressed() and rolls > 0:7
        chosen = chosen + 1
        if chosen == 5:
            chosen = -1         # back to all five
        else:
            display.show(chosen + 1)  # which die
            sleep(300)

    if button_b.was_pressed() and chosen >= 0 and rolls < 3:8
        held[chosen] = not held[chosen]
        if held[chosen]:
            music.pitch(880, 100)  # beep beep = held
            sleep(80)
            music.pitch(880, 100)
        else:
            music.pitch(440, 500)  # long beep = cleared

    if rolls == 0:9
        display.show("?")
    elif chosen >= 0:
        face = FACES[dice[chosen] - 1]
        if not held[chosen]:

        display.show(face)
    else:

  1. 1The dice faces, as pictures. You could design your own!
  2. 2Lists hold lots of values: five dice, and five True/False for which are held.
  3. 3Draw every die as a column of lights, bright if it's held.
  4. 4random.randint(1, 6) picks a number from 1 to 6, like a real die. Held dice are skipped.
  5. 5Shake to roll. After 3 rolls, the next shake starts a new turn.
  6. 6Turn over: a tune, then scroll the five numbers to write down.
  7. 7A picks the next die. After die 5, it goes back to showing all five.
  8. 8B flips the picked die between held and not held. not turns True into False and back.
  9. 9What to show: ? before the first roll, one die close up, or all five.

5Run it!

  1. Press ▶ on the pretend micro:bit to test it. Use its shake button to roll.
  2. Plug in your micro:bit and click Send to micro:bit (Chrome or Edge), or Save and drag the file onto the MICROBIT drive.
  3. The beeps need a micro:bit V2. A V1 plays silently.

More fun

  • Make held dice flash instead of shining brightly.
  • Give each player 4 rolls. Which number do you change?
  • Challenge: make the micro:bit spot five of a kind and play a fanfare!
