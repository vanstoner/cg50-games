# New Year

**When:** 1 January

## Project: Countdown Clock  *(planned)*

**The symbol:** The midnight countdown and the cheer when it hits zero.

**What you'll code:** Timers and big on-screen digits: counting down in real seconds, then a burst of colour at zero.

**The printable:** Design your own giant pixel digits 0–9 on a grid, then code them.
