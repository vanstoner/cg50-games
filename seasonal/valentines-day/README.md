# Valentine's Day

**When:** 14 February

## Project: [Beating Heart](beating-heart/)  ✅ Ready

**The symbol:** The heart, and Cupid's arrow.

**What you'll code:** Cupid's arrow flies through a stack of hearts inside hearts. When it hits, the little heart in the middle starts beating and sends ripples outward. You design the heart (and, on the Casio, the arrow) on paper first.

**Versions:**

| Device | Language | Code | Printable |
|---|---|---|---|
| Casio fx-CG50 | C | [casio/src/main.c](beating-heart/casio/src/main.c) | 📄 [PDF](beating-heart/printable/beating-heart-casio.pdf) |
| BBC micro:bit | Python | [microbit/main.py](beating-heart/microbit/main.py) | 📄 [PDF](beating-heart/printable/beating-heart-microbit.pdf) |

**The printables:** Two A4 sides each. Side 1 is design-only with a pencil, so it works on its own for younger children. Side 2 has the code with numbered notes, how to run it, and challenges.
