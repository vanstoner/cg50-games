# Valentine's Day

**When:** 14 February

## Project: [Beating Heart](beating-heart/)  ✅ Ready

**The symbol:** The heart, of course!

**What you'll code:** Pixel art as data. A grid of `#` and `.` becomes a picture on the screen, loops draw it, and the arrow keys make it grow and shrink.

**The printable:** Two A4 sides. Side 1 is design-only: colour a pixel heart on a grid and write it down as rows of `#` and `.`. No computer is needed, so it works on its own for younger children. Side 2 has the code, with numbered notes explaining each part, and how to run it on the calculator.
