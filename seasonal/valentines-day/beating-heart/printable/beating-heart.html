CODE A BEATING HEART

Design your own pixel art, then turn it into a real computer program that runs on a Casio graphing calculator!

You'll need

Part 1 (this side)

  • Coloured pencils
  • That's it!

Part 2 (other side)

  • Casio fx-CG50 calculator and its USB cable
  • A computer with the free fxSDK tools (a grown-up can help set these up)

1Design your heart

Colour in squares on the grid to make a heart. Then, on the line next to each row, write # for every coloured square and . for every empty one. Every row needs 9 symbols.

Like this!

.##...##.
####.####
#########
#########
.#######.
..#####..
...###...
....#....

Check: count the symbols in each row. There should be 9!

Design another!

A star? A smiley? Your initials? Use this grid, and swap it in later.

What's going on?

Every picture on a screen is made of tiny coloured dots called pixels. The calculator screen has 396 across and 224 down: that's 88,704 pixels!

Your rows of # and . are a map of your picture. Computers are brilliant at following maps like this. On the other side, a program reads your map row by row and draws a little square for every #.

Game makers designed characters exactly like this, square by square, for old games like Space Invaders and Pac-Man.

PART 2 · CODE IT

CODE A BEATING HEART

2Type the code

Type this into main.c, putting your rows from Part 1 in the pink part. Computers are fussy: every ;, bracket and quote mark matters!

#include <gint/display.h>
#include <gint/keyboard.h>
#include <gint/gint.h>

/* Your design! # = colour in, . = leave empty */
const char *HEART[] = {1
    ".##...##.",
    "####.####",
    "#########",
    "#########",
    ".#######.",
    "..#####..",
    "...###...",
    "....#....",
};

int main(void)
{
    gint_setrestart(1);2
    int size = 16;3
    int colour = C_RED;

    while (1) {4
        dclear(C_WHITE);
        int left = (DWIDTH - 9 * size) / 2;5
        int top = (DHEIGHT - 8 * size) / 2;
        for (int row = 0; row < 8; row++)6
            for (int col = 0; col < 9; col++)
                if (HEART[row][col] == '#') {
                    int x = left + col * size;
                    int y = top + row * size;
                    drect(x, y, x + size - 2,
                          y + size - 2, colour);
                }
        dupdate();7

        int key = getkey().key;8
        if (key == KEY_EXIT) break;
        if (key == KEY_UP && size < 24)  size = size + 2;
        if (key == KEY_DOWN && size > 4) size = size - 2;
        if (key == KEY_F1) colour = C_RED;
        if (key == KEY_F2) colour = C_RGB(31, 10, 20);
    }
    return 0;
}

What each part does

  1. 1Your design. Each "…" is one row of your grid.
  2. 2Lets you open the program again straight after you quit it.
  3. 3Variables: size is how many pixels wide each square is; colour is what colour to draw.
  4. 4Repeat forever: clear the screen, draw, wait for a key, and go round again.
  5. 5Work out where to start drawing so the heart sits in the middle of the screen, whatever its size.
  6. 6Two loops: visit every row, and every column in that row. Wherever your map has a #, draw a square.
  7. 7Show everything we've drawn.
  8. 8Wait for a key, then change the size or colour. EXIT stops.

3Run it!

  1. Build the program on the computer with fxsdk build-cg. It makes Heart.g3a.
  2. Plug in the calculator and press F1 (USB Flash).
  3. Copy Heart.g3a onto it, then eject it safely.
  4. Press MENU, find Heart, and press EXE.
