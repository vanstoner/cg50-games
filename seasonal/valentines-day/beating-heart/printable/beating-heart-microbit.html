CODE A BEATING HEART

Design a heart for the micro:bit's 25 lights, then code Cupid's arrow to fly through it and make it beat. You can even fire arrows at a friend's micro:bit!

You'll need

Part 1 (this side)

  • A pencil
  • That's it!

Part 2 (other side)

  • A BBC micro:bit and its USB cable
  • A computer with a web browser
  • Optional: a friend with another micro:bit

1Design your heart

The micro:bit has 25 lights in a 5 × 5 square. Write a number in every light to say how bright it should be: 0 is off and 9 is as bright as it goes.

Like this!

09090 99999 99999 09990 00900

Then write each row as 5 numbers:

09090
99999
99999
09990
00900

Brightness from 0 to 9:

024689

2Design the beat

Animations are pictures shown one after another, like a flick book. Draw two frames: first the little heart in the middle is bright, then the ring around it. Use small numbers (like 3) for dim lights.

Frame 1: inside bright

Frame 2: ring bright

What's going on?

Each light is an LED, a tiny light the computer switches on and off. Flicking it on and off super fast makes it look dimmer: that's how you get brightness 0 to 9.

Your numbers are a map of the picture. The program swaps between your frames so fast that the heart seems to beat, and Cupid's arrow flies right through it. 💘

CODE A BEATING HEART

3Type the code

Go to python.microbit.org and type this in, putting your designs from Part 1 in the pink parts. Python is fussy about spaces at the start of lines: they show which lines belong together.

# Beating Heart for the BBC micro:bit (MicroPython)
from microbit import *
import music
import radio

radio.on()1

# Your designs! Each number is how bright that light is:
# 0 = off, 9 = brightest
HEART = Image("09090:"2
              "99999:"
              "99999:"
              "09990:"
              "00900")

BEAT_IN = Image("03030:"     # the little heart in the
                "39393:"     # middle is bright...
                "39993:"
                "03930:"
                "00300")

BEAT_OUT = Image("09090:"    # ...then the ring
                 "93939:"    # around it
                 "93339:"
                 "09390:"
                 "00900")

def cupid():3
    # The arrow flies along the middle row, through the heart
    for x in range(7):
        picture = HEART * 0.3            # a dim heart behind4
        for i in range(3):               # the arrow is 3 lights long5
            if 0 <= x - i <= 4:
                picture.set_pixel(x - i, 2, 9 - i * 3)
        display.show(picture)
        sleep(90)
    music.play(["C6:1", "E6:1", "G6:2"], wait=False)6

cupid()
while True:7
    display.show(BEAT_IN)
    sleep(150)
    display.show(BEAT_OUT)
    sleep(150)
    display.show(HEART * 0.3)
    sleep(500)

    if button_a.was_pressed():8

    if button_b.was_pressed():9

What each part does

  1. 1Switch on the radio, so micro:bits can talk to each other.
  2. 2Your designs. Each "…:" is one row of lights.
  3. 3def makes a function: a recipe called cupid we can use whenever we like.
  4. 4HEART * 0.3 makes every light 3 tenths as bright: a dim heart.
  5. 5Light up the arrow: tip bright (9), then 6, then 3 for the tail. x moves it one step right each time.
  6. 6Play a little tune when it hits.
  7. 7Repeat forever: frame 1, frame 2, then rest. sleep(150) waits 150 milliseconds.
  8. 8Press A to fire another arrow.
  9. 9Press B to send an arrow to a friend by radio.
  10. 10If a friend's arrow arrives, fire it!

4Run it!

  1. Try it on the pretend micro:bit on the right of the page: press ▶.
  2. Plug in your micro:bit and click Send to micro:bit. (Or click Save and drag the file onto the MICROBIT drive.)
  3. Press A to fire again, B to fire at a friend.

More fun

  • Change the numbers in sleep(...). Can you make a racing heartbeat?
  • Make the arrow fly down the middle instead of across.
  • Challenge: add a third frame, so the beat ripples out even further.
