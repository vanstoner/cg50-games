CODE A BEATING HEART

Design a pixel heart and Cupid's arrow, then turn them into an animation on a Casio graphing calculator. The arrow flies through, and the heart comes alive!

You'll need

Part 1 (this side)

  • Coloured pencils
  • That's it!

Part 2 (other side)

  • Casio fx-CG50 calculator and its USB cable
  • A computer with the free fxSDK tools (a grown-up can help set these up)

1Design your heart

Colour in squares on the grid to make a heart. Then, on the line next to each row, write # for every coloured square and . for every empty one. Every row needs 9 symbols.

Like this!

.##...##.
####.####
#########
#########
.#######.
..#####..
...###...
....#....

Check: count the symbols in each row. There should be 9!

2Design Cupid's arrow

The arrow has a pointy tip and feathery tail. Make the middle row solid so they join up with the arrow's shaft.

Tip (3 wide)

Tail (4 wide)

Stuck? Try tip #.. ##. ### ##. #..
and tail ##.. .##. ..## .##. ##..

What's going on?

Every picture on a screen is made of tiny coloured dots called pixels. The calculator screen has 396 across and 224 down: that's 88,704 pixels!

Your rows of # and . are a map of your picture. On the other side, a program reads your map and draws a square for every #.

Here's the clever bit: it draws your heart 7 times, each one smaller than the last, on top of each other. Hearts inside hearts! Then it changes their colours over and over, so ripples seem to flow out from the middle.

CODE A BEATING HEART

3Type the code

Type both halves into main.c, with your designs in the pink parts. Every ;, bracket and quote mark matters!

#include <gint/display.h>
#include <gint/keyboard.h>
#include <gint/timer.h>
#include <gint/cpu.h>
#include <gint/gint.h>

/* Your designs! # = colour in, . = leave empty */
const char *HEART[] = {1
    ".##...##.",
    "####.####",
    "#########",
    "#########",
    ".#######.",
    "..#####..",
    "...###...",
    "....#....",
};
const char *TIP[] = {
    "#..", "##.", "###", "##.", "#..",
};
const char *TAIL[] = {
    "##..", ".##.", "..##", ".##.", "##..",
};

/* Draw a design with its top-left corner at x, y */
void draw(const char *design[], int rows, int cols,2
          int x, int y, int size, int colour)
{
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++)
            if (design[r][c] == '#') {
                int left = x + c * size;
                int top = y + r * size;
                drect(left, top, left + size - 1,
                      top + size - 1, colour);
            }
}

/* Draw the heart in the middle of the screen */
void heart(int size, int colour)3
{
    draw(HEART, 8, 9, DWIDTH / 2 - 9 * size / 2,
         DHEIGHT / 2 - 4 * size, size, colour);
}

The painter's trick 6 Things drawn later cover things drawn earlier, so the arrow seems to go through the heart:

back of arrow→hearts→front of arrow
int main(void)
{
    gint_setrestart(1);
    int mid = DWIDTH / 2, y = DHEIGHT / 2;
    int gold = C_RGB(28, 18, 2);
    int colours[3] = {C_RED, C_RGB(31, 14, 22), C_WHITE};
    int arrow = -10;   /* where the arrow's tip is */4
    int hit = -1;      /* when it hit (-1 = not yet) */
    int t = 0;         /* counts up 30 times a second */

    volatile int tick = 0;5
    int timer = timer_configure(TIMER_ANY, 33333,
                                GINT_CALL_SET(&tick));
    timer_start(timer);

    while (1) {
        while (!tick) sleep();
        tick = 0;
        dclear(C_WHITE);

        /* Back of the arrow, behind the hearts */6
        drect(arrow - 290, y - 1, arrow, y + 2, gold);
        draw(TAIL, 5, 4, arrow - 300, y - 9, 4, gold);

        /* Hearts inside hearts, biggest first */7
        int wave = 0;
        if (hit >= 0) wave = (t - hit) / 3;
        for (int k = 0; k < 7; k++)
            heart(24 - 3 * k, colours[(k + wave) % 3]);

        /* The little heart in the middle beats */8
        if (hit >= 0 && t % 20 < 4) heart(4, C_RED);
        else heart(3, C_RED);

        /* Front of the arrow, over the hearts */
        if (arrow > mid)
            drect(mid, y - 1, arrow, y + 2, gold);
        draw(TIP, 5, 3, arrow, y - 9, 4, gold);
        dupdate();

        if (arrow < mid + 150) arrow = arrow + 8;9
        if (hit < 0 && arrow > mid) hit = t;
        t = t + 1;

        clearevents();10
        if (keydown(KEY_EXIT)) break;
        if (keydown(KEY_EXE)) { arrow = -10; hit = -1; }
    }
    return 0;
}
  1. 1Your designs. Each "…" is one row of a grid from Part 1.
  2. 2A function is a recipe you can use again. draw turns any design into squares.
  3. 3heart draws your heart mid-screen, any size.
  4. 4Variables remember where the arrow is, when it hit, and the time.
  5. 5A timer ticks 30 times a second. The loop waits for each tick.
  6. 7Seven hearts, biggest first. wave grows over time, shifting each one to the next colour: ripples!
  7. 8Every 20 ticks, the little heart is big for 4 ticks: ba-dum!
  8. 9Move the arrow. When it passes the middle, the heart comes alive.
  9. 10EXIT stops. EXE puts the arrow back to fire again.

4Run it!

  1. Build it with fxsdk build-cg to make Heart.g3a.
  2. Plug in the calculator, press F1, copy it on, eject.
  3. MENU → Heart → EXE. Press EXE to fire again, EXIT to stop.

More fun

  • Swap the colours in colours[3]. Mix your own with C_RGB(red, green, blue), each 0 to 31.
  • Change 8 in arrow + 8. What happens?
  • Challenge: make the heart beat faster after each arrow.
