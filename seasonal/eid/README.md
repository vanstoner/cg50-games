# Eid

**When:** Eid al-Fitr ends Ramadan; Eid al-Adha follows about 70 days later (both move each year)

## Project: Eid Star Patterns  *(planned)*

**The symbol:** The beautiful geometric star patterns found in Islamic art, often used on Eid cards.

**What you'll code:** Geometry and rotation: build a star pattern by repeating and rotating one simple shape.

**The printable:** Draw a star pattern with a compass and ruler, then turn it into a card.
