# Winter Fun

**When:** January – February

## Project: Snowflake Maker  *(planned)*

**The symbol:** No two snowflakes are the same, but every one has six-fold symmetry.

**What you'll code:** Symmetry: draw one wedge and let the program mirror and rotate it six times.

**The printable:** Draw one wedge on a triangle grid and predict the whole snowflake.
