# Diwali

**When:** October – November (moves each year)

## Project: Rangoli Lights  *(planned)*

**The symbol:** Colourful rangoli patterns and rows of diya lamps.

**What you'll code:** Rotational symmetry: draw a quarter and let the program turn it into a whole rangoli.

**The printable:** Design a rangoli quarter on a grid and colour in the diyas.
