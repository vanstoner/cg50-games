# Hanukkah

**When:** November – December (moves each year)

## Project: Menorah Lights  *(planned)*

**The symbol:** Lighting one more candle on the menorah each of the eight nights.

**What you'll code:** Counting loops: pick the night, and the loop lights the right number of candles (plus the helper candle, the shamash).

**The printable:** Colour a menorah for each night and design the flame.
